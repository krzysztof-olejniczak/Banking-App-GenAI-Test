## General Documentation for test package

This package provides a basic framework for simulating bank account transactions. It includes classes for representing bank accounts (`BankAccount`) and managing fund transfers (`TransferService`). The `BankAccount` class allows for deposit, withdrawal, balance inquiry, and checks for sufficient funds. The `TransferService` facilitates transferring funds between accounts, ensuring validation and adherence to transfer rules. This package serves as a foundation for building more complex banking applications or testing financial systems.
